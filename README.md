# DAA-PRATICAL-9
 Summary

Prim’s algorithm is used to find the **Minimum Spanning Tree (MST)** of a weighted, connected, undirected graph. The algorithm repeatedly selects the minimum-weight edge and connects all vertices with minimum total cost.

 Conclusion

The C++ program successfully implements **Prim’s algorithm** and calculates the minimum cost of the spanning tree. It helps in efficiently connecting all vertices while minimizing the total edge weight.
